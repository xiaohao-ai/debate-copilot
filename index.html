麦克风没权限 / 点了没反应？点这里看：开“谁”的权限、在哪里开

权限有两层，缺一不可：① 操作系统给浏览器的麦克风权限；② 浏览器给“本页面”的麦克风权限。

第 0 步（最常见）：先换对浏览器。如果你是在豆包、微信等 App 的内置窗口里打开本页，内置网页通常不支持语音识别、也不发放麦克风。请关闭内置窗口，在文件夹里找到本文件，右键 →「打开方式」→ 选 Google Chrome 或 Microsoft Edge（或先打开 Chrome，再把文件拖进 Chrome 窗口）。

用「豆包流式识别」引擎时：除浏览器外，还要先在工具文件夹运行 node server.js，并从 http://127.0.0.1:8787 打开本页、在 config.json 填好火山密钥，详见同文件夹《使用说明.md》。

第 1 步 · 页面权限：在 Chrome/Edge 地址栏最左侧点「锁形 / 调节图标」→ 网站设置 → 麦克风 → 选「允许」→ 返回并刷新页面。

第 2 步 · 系统权限（macOS）：系统设置 → 隐私与安全性 → 麦克风 → 给 Chrome/Edge 打开开关 → 彻底退出并重开浏览器。

第 2 步 · 系统权限（Windows）：设置 → 隐私和安全性 → 麦克风 → 打开「麦克风访问权限」「允许桌面应用访问麦克风」。

第 3 步：确认麦克风没被会议/直播/录音软件占用，点上方「检测麦克风权限」，通过后再「开始收音」。

说明：语音转写走浏览器联网识别服务，需要联网；反驳话术匹配在本机离线运行，任何时候都能手动粘贴分析。
