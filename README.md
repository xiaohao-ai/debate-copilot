# 反方作战台 · Debate Copilot

> 辩题「AI 伴侣算真正的陪伴吗？」反方（立场：**不算真正的陪伴**）专用的辩论赛实时辅助工具。
> 实时收音转写 → 关键词命中预设反驳卡 → 豆包大模型按**辩位与环节时长**流式生成可直接照念的话术 / 完整逐字稿，另内置全队逐字稿、计时器、话术库、自定义卡片与陪练指引。

纯前端单页 + 一个**零第三方依赖**的 Node 本地代理，无需构建、无需框架，开箱即用。

---

## 两种使用方式

### 方式一：静态网页（GitHub Pages / 直接双击部署，零后端）

打开网页即可使用全部**离线功能**与浏览器自带语音识别；AI 生成采用「**浏览器直连火山方舟**」模式：

1. 到 [火山方舟控制台](https://console.volcengine.com/ark) 开通服务，并在「开通管理」里开通文本模型（默认 `doubao-seed-2-1-pro-260628`，可在页面里改）；
2. 在左下角「API Key 管理」创建 API Key；
3. 打开本工具 → 右侧「AI 现场生成」→ 展开「**AI 接入设置**」→ 粘贴你自己的 Key → 保存。

密钥只保存在你本人浏览器的 localStorage 中，随请求直接发往火山方舟官方接口（方舟已开放 CORS），**不经过任何第三方服务器**。清除浏览器数据或点「清除密钥」即删除。

> 静态网页下「豆包流式语音识别」引擎不可用（它依赖本地代理做二进制协议转发），会自动回退到「浏览器自带识别」（建议用系统 Chrome / Edge）。

### 方式二：本地全量模式（推荐正式比赛使用）

需要 Node.js 18+（无需 npm install，零依赖）：

```bash
# 1. 复制配置模板，填入火山语音 X-Api-Key 与方舟 arkApiKey
cp config.example.json config.json

# 2. 启动本地代理
node server.js

# 3. 用系统 Chrome / Edge 打开
#    http://127.0.0.1:8787
```

本地模式下：
- 语音：豆包「流式语音识别 2.0」（16k PCM，辩论术语识别更准，需在[火山语音控制台](https://console.volcengine.com/speech)开通并把 X-Api-Key 填入 `config.json`）；
- AI 生成：代理统一携带机主密钥调用方舟，同机访问者无需各自填 Key；
- `127.0.0.1` 是浏览器安全上下文，麦克风权限正常。

> 注意：不要用聊天 App 的内置浏览器打开；也不要用 `file://` 双击（非安全上下文 + 无法连接代理）。

## 功能一览

| 模块 | 能力 |
| --- | --- |
| 听对方 · 实时反驳 | 双引擎语音转写（浏览器 WebSpeech / 豆包流式识别）、10 类预设反驳卡关键词命中、交锋流水记录、手动粘贴兜底 |
| AI 现场生成 | 三档：**30 秒快反 / 按辩位完整成稿 / 继续延展 90 秒**；按辩位环节时长自动卡字数（约 240 字/分钟），流式上屏、字数-时长进度条、复制、朗读、随时停止 |
| 全辩位支持 | 一辩～十辩 + 通用，环节与时长依据 10v10 赛制手册：一辩 7′、二/三/六/七辩 6′、四辩 4′、五辩 1′、八辩 2′、九/十辩自由辩 5 张短打卡 |
| 我发言 | 七套内置逐字稿（立论/驳论/对辩弹药/自由辩战场/梳理/总结）、环节计时器、预设时长一键切换、全文朗读 |
| 话术库 | 10 类对方常见论点的拆解与反驳全文，可搜索、可朗读、可复制 |
| 自定义卡片 | 把陪练遇到的新论点写成反驳卡，自动进入实时匹配库，存于本机 |
| 陪练 | 豆包 App「一辩高下」对练流程指引与开局设定话术（该功能无公开 API，故做流程集成） |

反方理论框架已内置为提示词铁律：**三标准**（真实性 / 互主体性 / 共担性）、**三主线**（真实之缺 / 他者之缺 / 共担之缺）、总口径「陪伴感≠陪伴、止痛药≠健康、有用≠是」。

## 技术说明

- 前端：原生 HTML/CSS/JS，无构建、无框架；唯一外部资源为字体样式表。
- 代理：Node 内置 `http/https/crypto/zlib`，手写 WebSocket 编解码与火山二进制协议帧解析，**package.json 与 node_modules 都不需要**。
- 大模型：火山方舟 OpenAI 兼容接口，SSE 流式；默认关闭「深度思考」以保证现场首字延迟（约 1–3 秒）。
- 密钥安全：`config.json` 已在 `.gitignore`；任何真实密钥都不会进入仓库，也不会写进前端代码。

## 部署到你自己的 GitHub Pages

1. Fork 本仓库（或新建仓库推送本目录）；
2. 仓库 Settings → Pages → Source 选 `main` 分支根目录；
3. 约 1 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`；
4. 按页面内「AI 接入设置」填入你自己的方舟 Key 即可，把链接分享给队友——**每个人用自己的 Key、各自计费，互不可见**。
